# Phase 04.1 Plan 01: Token Foundation Summary

Transcribed the Claude Design handoff's OKLCH design-token system and its ~459-line
`dashboard.css` component-class layer into the dashboard's `globals.css`, re-pointed
Tailwind off the `hsl(var())` wrappers, swapped Inter/JetBrains Mono for self-hosted
Geist/Geist Mono, and created a shared `CHART_COLORS` constants module — the Wave-1
foundation that unblocks every downstream panel reskin.

## What Was Built

**Task 1 — OKLCH token system (`globals.css`).** Replaced the shadcn HSL slate ramp
with the handoff OKLCH tokens. Handoff-named tokens (`--bg`, `--surface`, `--accent`,
`--hedge`, `--r-1..4`, `--f-sans`, `--f-mono`, etc.) are transcribed verbatim from
`styles.css:9-54`. shadcn semantic aliases (`--background`, `--card`, `--primary`,
`--destructive`, `--ring`, ...) are re-pointed at the OKLCH values so all 13 installed
shadcn primitives inherit the reskin with no per-component edit. Dark values live in
both `:root` and `.dark` (no-class first paint is still dark); the `[data-theme="paper"]`
light override is placed under `.light` (the class next-themes actually toggles).
`body` uses `var(--bg)`/`var(--text)`/`var(--f-sans)` + `ss01/ss02/cv11`; `i`/`em`
forced upright (no italics).

**Task 2 — handoff component-class layer (`globals.css`).** Transcribed the full
`dashboard.css` component layer into `@layer components`: shell (`.dash-body`,
`.dash`), rail (`.rail*`, `.ri-dot`), top bar (`.db-bar*`, `.crumb`, `.db-pill`,
`.db-avatar`), headline (`.db-headline`, `.dh-*`), row grid (`.db-row`, `.r1/.r2/.r3`),
card chrome (`.db-card`, `.db-h`, `.db-mark`, `.db-tabs`, `.db-foot`), SVI card
(`.svi-*`), `.db-side`, bucket (`.bucket*`), `.oracles`, positions table
(`.pos-table`, `.leg-dot`, `.chip`), what-if (`.shock*`, `.ss-row`, `.sb-*`), event
list (`.ev-list`, `.ev-k`), `.db-end`, and the 1200/1024/900px responsive breakpoints.
Transcription was verbatim — the handoff CSS already references `var(--bg)` etc., so
every rule resolves to the Task-1 tokens with no raw hex. Excluded the dropped Greeks
panel class group (LD-1) and the live backtest-replay class group (LD-3).

**Task 3 — Tailwind config + Geist fonts.** Dropped the `hsl(var())` wrapper on every
color token (OKLCH is not HSL) — Tailwind now consumes raw `var(--token)`. `fontFamily`
switched to Geist / Geist Mono; added `r1/r2/r3/r4` borderRadius aliases. `package.json`
swapped `@fontsource-variable/inter` + `@fontsource/jetbrains-mono` for
`@fontsource-variable/geist` (5.2.9) + `@fontsource/geist-mono` (5.2.8); `main.tsx`
imports the Geist variable sans + Geist Mono weights 300/400/500/600 (provider order
unchanged). `pnpm install` ran; lockfile committed.

**Task 4 — `CHART_COLORS` constants.** Appended `CHART_COLORS` to
`dashboard_constants.ts` — sRGB-hex equivalents of the OKLCH tokens (accent `#5efaa2`,
accentDim `#4ed589`, hedge `#fa695c`, hedgeDim `#d24d42`, text2, muted, gridLine,
surface, cardBg, text), each documented with its source OKLCH. Also exported
`MINT_COLORSCALE` (SVI surface gradient) and `CHART_FONT_FAMILY` / `CHART_FONT_FAMILY_MONO`
Geist strings. Chart libs cannot read CSS vars at runtime; this is the single source
of truth for Wave-3+ panels.
