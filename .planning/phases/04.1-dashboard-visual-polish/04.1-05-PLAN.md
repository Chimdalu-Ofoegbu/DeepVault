<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| relay WSS feed -> EventStreamPanel render | event name/description strings from an external relay feed are rendered into the DOM |
| localStorage <-> next-themes | theme preference persisted to localStorage and read at pre-paint |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04.1-13 | Tampering / XSS | EventStreamPanel event rendering | mitigate | Event strings from the relay WSS feed are rendered as plain React children — React escapes them by default. Task 1 acceptance criterion greps to confirm NO `dangerouslySetInnerHTML` in the component. A malicious relay payload cannot inject markup. |
| T-04.1-14 | Tampering | next-themes localStorage pre-paint | accept | next-themes' pre-paint script is the library's own sanitized inline script reading a constrained value ('light'/'dark'); Task 2 forbids a custom eval/innerHTML pre-paint. localStorage is same-origin; a tampered theme value at worst yields a wrong theme, not code execution. |
| T-04.1-15 | Denial of service | ev-list growth | mitigate | The list is capped at ~14 rendered rows and the ring buffer is server-capped at 100 (useWebSocket applyEvent) — unbounded growth is structurally prevented. |
</threat_model>
