## Accomplishments

- **SVI-draw loader** (`DashboardLoader.tsx`): full-viewport overlay that plays the brand-mark + animated SVI line-draw on first paint, then fades out via a `.gone` class and unmounts — purely presentational, never blocks the `useWebSocket` connection or any data fetch.
- **Motion CSS layer** appended to `globals.css`: `@keyframes pulse` (box-shadow ring for the live/net dots), `@keyframes dash` (`stroke-dashoffset -> 0` for the loader), `.12s`–`.15s` hover/focus transitions on rail items / cards / positions-table rows / event-list rows / shock buttons / db-tabs, all recolored to the Plan-01 OKLCH tokens (no raw hex).
- **Accessibility:** a `prefers-reduced-motion: reduce` media query disables the pulse + loader animation and the loader dismisses near-immediately under reduced motion.
- **Interactive motion wired:** live-dot pulse on the relay status pill; the shock-button active toggle, event-ticker 700ms flash, and db-tabs underline confirmed to line up with the Task-1 CSS (class-application only — no behavior changed).
- **Scope discipline:** the landing-page-only `lineDraw` / `fade-in` / scroll-reveal keyframes were deliberately excluded (those belong to `index.html` per the UI-SPEC).
