## TOP SECTION: Data Layer Map (handoff data needs → existing dashboard wiring)

The reskin must NOT touch the data layer (CONTEXT D-01, UI-SPEC Out-of-Scope). Every
panel already receives its data through one of three established channels. The
`EventStreamPanel` (the one new data wire) reuses the **same WebSocket snapshot
channel** — no new hook, no new socket.

### The single data spine — `useWebSocket` → `FullSnapshot`

`dashboard/src/App.tsx` lines 42-48 is the canonical wiring. ALL data flows from one
`useWebSocket` call, then derived hooks select slices:

```typescript
// App.tsx:42-48 — the entire data layer, one spine
const { state, snapshot } = useWebSocket(env.relayWsUrl);
const surface   = useSurfaceSnapshot(snapshot);  // SurfacePanel, ArbCheckerPanel
const vaultView = useVaultState(snapshot);       // VaultPanel, dh-stats strip, DepositWithdrawPanel
const hedges    = useExposure(snapshot);         // ExposurePanel, WhatIfSimulator
const sigma     = useSigmaEstimates(snapshot);   // WhatIfSimulator
const positions = usePositions(snapshot);        // PositionViewer
```

| Channel | Source file | What it carries | Consumers |
|---------|-------------|-----------------|-----------|
| **Relay WebSocket** | `useWebSocket.ts` → `WsClient` (`lib/wsClient.ts`) | `FullSnapshot` = `{ oracles[], vault, ring_buffer[], served_at_ms }` + `WsState` machine | every panel (via derived hooks) |
| **Derived selectors** | `useSurfaceSnapshot`, `useVaultState`, `useExposure`, `useSigmaEstimates`, `usePositions` — all `useMemo`'d on `snapshot` | typed slices of the snapshot | the 8 panels |
| **On-chain RPC** | `useBucketState.ts` (stubbed v1), `usePositions.ts` direct reads, `useCurrentAccount()` from dapp-kit | per-user bucket, wallet address | BucketGauge, PositionViewer, DepositWithdrawPanel |
| **Codegen constants** | `lib/strategy_constants.ts`, `lib/dashboard_constants.ts` | hedge ratio band, cooldown, `FALLBACK_FORWARD_PRICE_DUSDC` | dh-stats target band, WhatIfSimulator |

### EventStreamPanel data wire (D-03) — NO new wire needed

The relay event ring buffer ALREADY arrives in `FullSnapshot.ring_buffer` and is
already kept live-updated client-side. `useWebSocket.ts:61-75` `applyEvent()` appends
every `{type:'event'}` frame to `snapshot.ring_buffer` (100-cap, mirrors server).

**`EventStreamPanel` consumes `snapshot.ring_buffer` directly** — a `RingEvent[]`
(`{ name, ts_ms, data }`, see `lib/types.ts:52-56`). Pass `snapshot` (or
`snapshot?.ring_buffer ?? []`) from `App.tsx` exactly like the other panels. The
handoff's `dashboard.js` `setInterval` synthetic generator (lines 54-79) is
REPLACED by this real array — UI-SPEC #9 mandates this.

The prepend+highlight ticker behavior is pure client-side render state (a 700ms flash
on the newest row), NOT a data concern — see the EventStreamPanel CREATE section.

### Relay state for the "live" pill

`WsState` (`'connecting'|'live'|'reconnecting'|'down'`, `types.ts:88`) already drives
`RelayStatusPill`. The handoff's `live · testnet` pill + pulsing `live-dot` maps onto
this — reskin colors only, keep the state machine.

**Divergence vs UI-SPEC:**

2. **Token names:** must add the handoff-named tokens (`--bg`, `--bg-2`, `--surface`, `--surface-2`, `--border`, `--border-2`, `--text`, `--text-2`, `--muted`, `--dim`, `--accent`, `--accent-2`, `--hedge`, `--hedge-2`, `--r-1..4`) AND keep the shadcn semantic aliases (`--background`, `--card`, `--primary`, `--destructive`, `--border`, `--ring`...) re-pointed at OKLCH values (UI-SPEC R-3) so the 13 shadcn primitives inherit the reskin.
3. **Theme mechanism:** UI-SPEC §Design System offers two valid paths — keep `next-themes` `.dark` class and map handoff `:root`→`.dark`, `[data-theme="paper"]`→`:root`; OR switch to `[data-theme]` attribute. 4. **`hsl(var(...))` wrappers:** `tailwind.config.ts:19-53` wraps every token in `hsl()`. OKLCH values are NOT HSL — the config color entries must drop the `hsl()` wrapper (or move to raw `var(--token)`). This is a required tailwind.config.ts edit, not just a CSS edit.
