>

## Mode Toggle Contract (NEW — primary deliverable)

The core new interaction. A two-option segmented control that switches the entire main-content region between **Vault** (default) and **Risk Studio**.

### Placement & structure

- **Location (OQ-1):** top of `main.dash`, **directly below the `db-headline` section and above the first content row**, full-width-left-aligned. It sits inside the scroll flow (not sticky) so it reads as the section divider between "who you are / your money" (Vault) and "prove it's safe" (Risk Studio).
- **`dh-stats` strip (OQ-2):** remains in the `db-headline`, visible in **both** modes, unaffected by the toggle.
- **DOM:** Radix `Tabs` (`<Tabs value={mode} onValueChange={setMode}>`), with a `TabsList` containing two `TabsTrigger`s (`value="vault"`, `value="risk"`). The Vault and Risk Studio content regions are siblings rendered conditionally on `mode` (NOT via `TabsContent` mounting both — see § Mounting below).

### Visual treatment (inherited tokens only)

A segmented (pill-group) control, drawn from the existing token system — no new CSS variables:

| Element | Style |
|---------|-------|
| `TabsList` container | `display: inline-flex`; `background: var(--bg-2)`; `border: 1px solid var(--border)`; `border-radius: var(--r-2)` (8px); `padding: 3px`; `gap: 2px`. |
| `TabsTrigger` (inactive) | `font-family: var(--f-mono)`; `font-size: 12.5px`; `font-weight: 400`; `color: var(--muted)`; `padding: 7px 16px`; `border-radius: 6px`; `background: transparent`; `transition: color .12s, background .12s`. |
| `TabsTrigger` (hover, inactive) | `color: var(--text-2)`. |
| `TabsTrigger` (active, `data-state="active"` / `aria-selected="true"`) | `color: var(--text)`; `background: color-mix(in oklab, var(--accent) 12%, var(--surface))`; the active pill carries a `1px` inset feel via `background` only (no border to avoid 1px jitter). Active label weight stays 400 (the type contract forbids bumping to bold for state — color + bg carry it). |
| Label copy | `Vault` and `Risk Studio` (exact). Optional leading `ri-dot` (5px) per trigger, mint when active — reuses the existing `.ri-dot` rail idiom for visual kinship; allowed but not required. |

**Color discipline:** the active-state mint tint is the **same accent reservation** as the active rail item (`color-mix(accent 10–12%)`) — this is an explicitly-listed accent use (active nav state), not a new accent surface. Coral (`--hedge`) MUST NOT appear on the toggle.

### Accessibility contract (CONTEXT hard requirement)

| Requirement | Implementation |
|-------------|----------------|
| Tablist semantics | `role="tablist"` on the list, `role="tab"` on each trigger (Radix `Tabs` provides these). |
| Selection announced | `aria-selected="true"` on the active tab, `false` on the other (Radix-provided). |
| Roving focus | Single tab stop into the group; **←/→ arrow keys** move between tabs; **Home/End** jump to first/last (Radix `Tabs` default `loop` behavior). |
| Activation | Default Radix `activationMode="automatic"` — focus moves selection. Acceptable here because switching modes is cheap and non-destructive (no form loss). |
| Visible focus | Focused trigger shows a `2px` outline in `var(--ring)` (= mint) via `:focus-visible` — the `--ring` token already exists. Never remove the focus ring. |
| Labeling | `TabsList` gets `aria-label="Dashboard view mode"`. |
| Orientation | `orientation="horizontal"` (default) so ←/→ (not ↑/↓) drive it. |

### Mounting & state behavior

- **Default mode:** `vault` (LD-1). `App.tsx`: `const [mode, setMode] = useState<'vault' | 'risk'>('vault')`.
- **Conditional render, not CSS hide:** the inactive mode's panels are **unmounted** (`{mode === 'vault' ? <VaultView/> : <RiskView/>}`), not `display:none`. Rationale: avoids running two surface/Plotly trees simultaneously and keeps the existing per-panel hooks reading the single shared `snapshot` without doubling work. The `useWebSocket` spine and all hooks live **above** the conditional (in `App`), so unmounting a view never tears down the data spine (LD-3 preserved).
- **No persistence:** mode is in-memory React state only (LD-2). No `localStorage`, no URL. A refresh returns to Vault default. (ThemeToggle's `localStorage` persistence is unrelated and unchanged.)
- **Toggle is the ONLY thing that swaps views.** The rail couples *into* `setMode` (OQ-3) but the tablist is the canonical control.

### Rail behavior contract (OQ-3 + R-4)

1. **Mode-switch-then-scroll:** clicking a rail item whose `mode` differs from the current mode calls `setMode(item.mode)` FIRST, then scrolls to `item.anchor`. Because the target section is only mounted after the mode switch, the scroll must run **after** the mode-switched render commits (e.g. `setMode(...)` then scroll in a `requestAnimationFrame`/`setTimeout(0)` / `useEffect` keyed on mode — executor's call; the contract is "the scroll always lands, never no-ops").
2. **Same-mode click:** behaves as today — smooth-scroll to the anchor (`scrollIntoView({behavior:'smooth', block:'start'})`).
3. **Active-item tracking:** the existing `IntersectionObserver` pattern is kept, but `OBSERVED_SECTIONS` is **reconciled to the actually-mounted anchors of the current mode** (R-4). When `mode === 'vault'`, observe `[top]`, `deposit-withdraw`, `position-viewer`; when `risk`, observe `hero`, `what-if`, `backtest` (+ `event-stream`/`exposure` if those items exist). The active rail item reflects both the current mode (items of the inactive mode are never "active") and the scrolled-to section.
4. **Active style:** unchanged — `.rail-nav a.active` (10% accent-mix bg + mint `ri-dot`). This is an explicitly-listed accent use; no change.
5. **`event-stream` anchor reconciliation (R-4):** whatever the final rail item set, the rail's observer/targets and the `App.tsx` `data-section` values MUST agree. The stale `History → exposure` mapping is removed; if an Activity item exists it points at `event-stream` (the real anchor App.tsx already renders).

### Rail footer & brand

Unchanged (`← Back to site`, `net-dot` + `testnet · 0x…` meta, brand mark + `DeepVault` wordmark). Reuse verbatim.
