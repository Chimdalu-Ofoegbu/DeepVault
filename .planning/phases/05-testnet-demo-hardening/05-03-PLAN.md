```typescript
function navPerShareScaled1e9(snap: SnapshotJson): bigint {
    const ta = BigInt(snap.total_assets);
    const ts = BigInt(snap.total_shares);
    if (ts === 0n) return 0n;
    return (ta * 1_000_000_000n) / ts;
}
```

Dual ±10 bps gate math (RESEARCH §"±10 bps tolerance gate"):
```
// Framing 1 — Per-depositor return ratio
// received_quote >= deposited_quote * (10_000 - allocation_bps - 10) / 10_000
// For 50 DUSDC + 10% alloc + 10 bps slack: 50_000_000 * (10000 - 1000 - 10) / 10000 = 49_950_000 micro
// 99.9% of (deposit * (1 - alloc/10000)) = 0.999 * 45_000_000 = 44_955_000 — use the stricter "99.9% of full deposit minus alloc minus 10bps"
// Both framings of "≥99.9%" are equivalent; the plan locks the per-depositor formula:
//   minReceived = (deposit * (10_000n - allocBps - 10n)) / 10_000n

// Framing 2 — Vault NAV drift
// navDeltaBps = abs(navPost - navPre) * 10_000n / navPre <= 10n
```

DUSDC type tag for testnet: read from `TESTNET-DEPLOY.json` field `dusdc_type_tag` (already populated from Phase 2 deploy)
DUSDC decimals: 6 → 50 DUSDC = 50_000_000 micro-units
